# VOX

End-to-end encrypted voice chat, text chat and screen sharing for a private, invite-only server.

Get `voice.exe` from the [latest release](https://github.com/PTAV-CH/vox/releases/latest). The release notes give its SHA256; to check your download:

```
certutil -hashfile voice.exe SHA256
```
